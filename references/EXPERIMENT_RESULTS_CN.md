# Motion Context × 彩噪注入：机制分析与 POC 方案

> **实验记录**，2026-08-12  
> **状态**：单接缝 POC 与 60 秒多段链验证均已完成；本文保留实验设计与后续实测结果
> **前置阅读**：`RESULT.md`（v5 Track 1）、`../MOTION_CONTEXT_WORKFLOW.md`、`../../EXPERIENCE.md` §11  
> **触发**：跨链锐度审计发现彩噪注入当年不仅压住了彩噪/变暗/zoom，还把锐度衰减砍掉一半以上（见文末附表），而 MC 路线目前无此收益。

## 1. MC 机制回顾（有实测证据）

`MiniMaxH3ChainContext`（`encode_mode=video`, `anchor_mode=head`, `context_length=22`）：

- 上一段 A 尾部 22f 经 **video VAE 编码为 latent**，作为 7 个 cond token block 钉在 B 的**目标时间轴头部**（H3 `(1,4,4,4,4)` 覆盖位置 0,1,5,9,13,17,18）。
- **context 覆盖区（raw B 0..21）≈ 像素级复刻**：v5 treatment 对角线 diff `0.0035`（纯编解码损耗），随后被 `trim 22` 裁除，不进入交付。
- **交付区（B 22..123）**：在 context token + Video1 + 身份图 + prompt 联合条件下自由生成；接缝 `0.0176` ≈ A 原生运动 `0.0184`。
- **context 同时钉住外观统计量**：MC 链（full60_mc_reroll seg2-7）段内锐度变化仅 ±5（Laplacian 方差），损失全部发生在接缝台阶上。模型把 context 的质感当"过去真实状态"延续。

## 2. 与 Video2 注入实验的机制差异（核心论点）

| | 老 Video2 注入（EXPERIENCE §11） | MC context 注入（假设） |
|---|---|---|
| 噪声载体角色 | **软参考**：模型重新渲染每一帧 | **锚定的目标时间轴 token**：被视为既成历史 |
| 噪声直接进入输出？ | 不会（ref 不出现在输出） | context 区会近像素级复刻，**但该 22f 被 trim** |
| 模型态度 | "参考脏了" → 保守修复模式，输出更干净 | 未知 = 本 POC 要回答的问题 |

关键推理素材：

1. **时间不相干性**：注入彩噪每帧独立随机，视频扩散先验无法"延续"它——当年 Video2 修复模式成立的一半原因在此，换到 context 通道该性质不变。
2. **一致性压力随距离衰减**：交付帧离 context token 越近，延续 context 统计的压力越强；远段回归模型先验。
3. **锐度证据指向"一致性模式"**：MC 链上模型并未把偏软的 context"修复"回身份图锐度，而是忠实延续——连续纹理统计上，consistency 压过 repair。彩噪是离散伪影 + 时间不相干，行为可能不同，这正是需要实测的部分。

## 3. 分区域行为预测

| 区域 | 预测 | 置信度 |
|---|---|---|
| context 覆盖区（raw B 0..21） | 复刻彩噪（VAE 编解码保真度足够）；**trim 后无害** | 高 |
| 交付区近段（~22..45） | 彩噪衰减式拖尾 / 偏色残留的风险区 | 中 |
| 交付区远段（~45..123） | 修复模式占优，输出干净；**若修复触发，可能连带把锐度刷回模型先验水平**（=本次真正想要的收益） | 中低 |
| 运动继承 | ⚠️ 隐患：色块向 latent 灌高频垃圾，可能污染 cond token 的运动线索，削弱相位锁定（MC 的核心收益） | 必须实测 |

**灾难情形（整条交付区忠实复刻彩噪）概率评估为低**，但"近段拖尾 + 运动锁定退化"是完全可能的真实代价。

## 4. POC 设计（单 seam，复用 v5 资产）

**资产全部现成**：`../inputs/A_keep_src000_106_107f_noaudio.mp4`、`B_video1_src085_208_124f_noaudio.mp4`、`workflow_v5_motion_context_s20203.json`、四张身份图。

### 4.1 变体

| 变体 | 注入范围 | 剂量 | 目的 |
|---|---|---|---|
| T1 | 仅 A_keep 最后 22f（context 本体） | 0.45 | 最小干预：锚点带噪 |
| T2 | 仅 A_keep 最后 22f | 0.20 | 剂量下限，找运动锁定的安全线 |
| T3（最终采用） | A_keep 最后 22f：前 19f 固定注噪，末 3f 渐弱 | 0.45 → 0.33 / 0.22 / 0.10 | 保留锐度收益，同时消除接缝端彩噪残留 |

注入方式沿用 EXPERIENCE §11 的紫绿色块（0.45 alpha 甜点已验证平顶；`tools/noise_scan.py` 或当年 `inject_variant.py` 的实现）。**A 的交付部分不受影响**——POC 只观察 B 的行为，final 时间账不变。

### 4.2 执行

- 全部跑在 **4080S / 8188**（当前被 full60 reroll 占用，排队即可，单次 ~20 min）。
- seed 固定 `20203`（与 v5 treatment/control 直接可比）。
- 对照基线：v5 treatment 现有数据（`treatment_s20203_*`）。

### 4.3 验收指标（按优先级）

1. **运动继承是否存活**：`audit_overlap_sync.py` 对角线（基线 0.0035）、接缝 diff（基线 0.0176）。退化 >50% 即判注入剂量不可接受。
2. **彩噪是否漏入交付区**：交付 22..123 的 HSV-S 均值/方差 vs 基线；近段/远段分开统计。
3. **锐度收益（核心问题）**：交付区 Laplacian 方差 gen/src 比值 vs 基线 treatment 同区间；若修复模式触发，应看到显著回升（参考：老链注入 vs 无注入差 ~1.5-2x 斜率）。
4. **phase screen**：`audit_motion_phase_screen.py`（仍是筛选器，不是 pose 认证）。

### 4.4 判读矩阵

| 结果 | 结论 |
|---|---|
| 交付区干净 + 锐度回升 + 运动锁定存活 | 🎉 组合路线成立：MC 锁动作、注入刷细节，进 full-chain POC |
| 交付区干净 + 锐度无变化 | 修复模式未转移；注入对 MC 无收益，放弃此方向 |
| 近段彩噪拖尾 | 尝试更低剂量 / 只注入 context 前半 / 放弃 |
| 运动锁定退化 | 剂量超限；T2 数据决定是否存在安全窗口 |

## 5. 实测结果（2026-08-12，4080S，seed 20203）

T1/T2/T3 全部完成。数据目录：`../noiseinj_poc_20260812/`（outputs/ 内为 raw/trim/final MP4）。

| 指标 | 基线（无注入） | T1（全0.45） | T2（全0.20） | **T3（taper）** |
|---|---|---|---|---|
| 交付区锐度 gen/src | 0.792 | 0.865 | 0.791 | **0.855** |
| 接缝 diff / ratio | 0.0175 / 1.69x | 0.0400 / 3.87x | 0.0255 / 2.47x | **0.0198 / 1.96x** |
| phase screen offsets | +1/+2/-8 | +1/+2/-8 | +1/+2/-8 | **+1/+2/-8** |
| HSV-S 近段/远段 | 27.7 / 27.6 | 23.9 / 24.9 | 23.0 / 23.7 | 24.8 / 25.1 |
| f22-23 残留 | 无 | 明显（人工判不可接受） | 几乎不可见 | **零残留（contact sheet 确认）** |

### 判读（对照 §4.4 矩阵）

- **修复模式可通过 context 通道触发**，阈值在 0.20~0.45 之间：T1 锐度 +9.2%，T2 完全无收益且仍损接缝——**低剂量注入被严格支配，不要做**。
- T1 的代价是 f22-23 噪声拖尾（静态斑点，播放时闪烁），恰好落在交付区头 2 帧。
- **T3（尾部渐变方案）三项全绿**：保住 T1 锐度收益的 98.8%（0.855/0.865），接缝回落到基线水平（0.0198 vs 0.0175），相位逐项一致。机制解释：修复触发器放在 context 远端（前 19f @0.45），一致性压力最强的接缝端 3f 渐变为 0.33/0.22/0.10，模型在接缝处没有脏状态可延续。
- **结论：组合路线成立——MC 锁动作 + context 注噪触发修复刷锐度 + 尾部 taper 保接缝。三个机制互不干扰。**

### 后续 60 秒多段链验证

多段链验证已完成。相同任务中，第 2–5 段的锐度比值为：

- 无渐弱注噪：`0.790 / 0.740 / 0.742 / 0.648`
- 渐弱注噪：`0.831 / 0.833 / 0.872 / 0.789`

整体提升约 8–9%，并且交付区未观察到彩噪残留。它说明收益能够跨多代持续，但没有解决动作时序本身：难段尾部仍可能领先、落后或复读。当前 3 帧线性渐弱是首个可行点，不代表全局最优；不同分辨率、镜头类型和参考图配置仍需重新验收。
